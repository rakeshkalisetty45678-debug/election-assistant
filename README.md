# Election Assistant

## Problem Statement
Build an assistant that helps users understand election process, timelines, and steps.

## Solution
This project is a simple backend assistant built using Node.js and Express.

## Features
- Explains how to vote
- Provides election process steps
- Guides voter registration
- Interactive API (/chat endpoint)

## How it works
User sends a message → Server processes keywords → Returns response.

## Tech Stack
- Node.js
- Express.js
